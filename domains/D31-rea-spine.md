## Decision tree

Machine readable at `trees/D31.json`. This is the rendered view.

- **What do you already have: nothing, a capture, or a client artifact?**
  - _why:_ Each starting point has a different cheapest path, and starting at the wrong one wastes the most expensive resource, which is attention.
- `Nothing yet`
  - action: browse once through the proxy, then inventory the capture. no probing
  - tools: `d31-mitmproxy`, `d31-capture`
  - oracle: `endpoint inventory grounded in bytes`
- `A capture`
  - **Does the capture include response bodies for scripts and API calls?**
  - `Yes`
    - action: export scripts, analyze the bundle, then map endpoints to source locations
    - tools: `d31-export-web-scripts`, `d31-analyze-web-bundle`, `d31-source-location`
    - oracle: `route present in bundle and absent in capture`
  - `No`
    - action: recapture with bodies enabled. a capture without bodies cannot answer the questions that matter
    - tools: `d31-mitmproxy`
    - oracle: `n/a recapture`
- `A client artifact (APK, IPA, asar, wasm)`
  - **Is the logic in bytecode or in a bundle inside the package?**
  - `Bytecode`
    - action: inspect the package, then class or method level, then trace references to the API client
    - tools: `d31-android`, `d31-android-class`
    - oracle: `endpoint or secret recovered from code`
  - `Bundle`
    - action: extract, then treat as a web bundle. check for webview bridge code
    - tools: `d31-artifact`, `d31-analyze-web-bundle`
    - oracle: `bridge interface recovered`
  - `WASM`
    - action: validate and read imports and exports. the interface is the contract
    - tools: `d31-wasm`
    - oracle: `import and export list`
- `Only a URL`
  - action: fetch the page, inventory scripts and storage keys, then decide what to acquire next
  - tools: `d31-inspect-web-page`, `d31-analyze-web-bundle`
  - oracle: `script and storage inventory`

## Defense mirror

The other half of every row. An offensive entry with no matching detection and control is
incomplete, because the practical question is always against which defence.

| attack | detect | control | rule |
|---|---|---|---|
| source map exposure | a .map file served in production | do not publish maps, or publish without sourcesContent | map request in production logs |
| secret in bundle | key-like strings in shipped JS | no secrets client side, short lived tokens | secret pattern in served asset |
| debug endpoint exposure | debug or dev routes in the bundle | build time stripping, environment gating | dev route request |
| webview bridge abuse | bridge method callable from loaded content | allowlist origins and methods | bridge call from unexpected origin |
| WebMCP tool exposure | page registers tools with broad schemas | declare only what is needed, validate inputs | tool registration change |
