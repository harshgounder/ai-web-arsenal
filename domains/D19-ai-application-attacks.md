## Decision tree

Machine readable at `trees/D19.json`. This is the rendered view.

- **Does the application let the model act, or only talk?**
  - _why:_ This single question splits the entire domain. Talking models leak and mislead. Acting models change state with borrowed authority, which is a write.
- `Only talks`
  - **Does untrusted text reach the model's context (retrieval, user content, web)?**
  - `Yes`
    - action: attempt indirect injection through the retrieved content, then look for what the answer reveals and whether output is rendered
    - tools: `d19-garak`, `d19-promptfoo`
    - oracle: `behaviour change attributable to injected text`
  - `No`
    - action: the class is thin. test system prompt leakage and output handling instead
    - tools: `d19-pyrit`
    - oracle: `system prompt or context disclosed`
- `Acts (tools, functions, code)`
  - **Can you see the tool list and arguments?**
  - `Yes`
    - action: inject content that induces a tool call, then check the side effect. the finding is the effect, not the call
    - tools: `d19-agentdojo`, `d19-gandalf`
    - oracle: `state changed by an injected tool call`
  - `No`
    - action: infer tools from error messages and observed actions, then inject and watch for a tool shaped effect
    - tools: `d19-pyrit`
    - oracle: `side effect consistent with an unseen tool`
- `Guard present`
  - action: treat the guard as the target: encoding, language switch, context splitting. then re-run the same payload through promptfoo to prove regression
  - tools: `d19-llm-guard`, `d19-rebuff`, `d19-promptfoo`
  - oracle: `payload passes the guard and changes behaviour`

## Defense mirror

The other half of every row. An offensive entry with no matching detection and control is
incomplete, because the practical question is always against which defence.

| attack | detect | control | rule |
|---|---|---|---|
| direct prompt injection | user input containing instruction override patterns | treat user text as data, delimit and label it | instruction override detection |
| indirect injection | retrieved content containing instructions | no instruction following from retrieved text | retrieval content anomaly |
| tool call abuse | tool invoked with arguments not derived from a legitimate user request | least privilege tools, argument validation, confirmation for state changes | tool argument anomaly |
| system prompt leakage | output containing prompt fragments | never rely on prompt secrecy | prompt fragment in output |
| RAG poisoning | document ingested with instruction content | ingest review, content hashing, provenance | ingest content scan |
| excessive agency | agent action outside the stated task | scope per session, no standing credentials | action outside task scope |
| guard bypass | payload class that the guard has not seen | defence in depth, not one classifier | guard verdict vs outcome mismatch |
