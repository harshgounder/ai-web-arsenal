## Decision tree

Machine readable at `trees/D10.json`. This is the rendered view.

- **Is there a shared cache in front of the app?**
  - _why:_ Without a shared cache there is no class here. Confirm with headers and age before spending time on keying.
- `Unknown`
  - action: read the response headers and repeat one request. age, x-cache and cf-cache-status answer it
  - tools: `d10-curl`
  - oracle: `cache hit indicator`
- `Yes, and you want poisoning`
  - action: vary headers one at a time and watch the cached response. the first input that changes it and is not in the key is the opening
  - tools: `d10-wcvs`, `d10-mitmproxy`
  - oracle: `a second clean session receives your value`
- `Yes, and you want deception`
  - action: find a private route the cache will store under a static looking path, then request it without a session
  - tools: `d10-wcvs`, `d10-ps-deception`
  - oracle: `private content served without authentication`
- `No shared cache`
  - action: no finding. say so and move on
  - oracle: `n/a`

## Defense mirror

The other half of every row. An offensive entry with no matching detection and control is
incomplete, because the practical question is always against which defence.

| attack | detect | control | rule |
|---|---|---|---|
| cache poisoning | cached response containing attacker influenced content | key every varying input, never cache by default | response variance per unkeyed input |
| cache deception | private page cached under a public path | cache only explicit routes, normalise before keying | cache hit on an authenticated route |
| cache key normalisation abuse | origin and cache disagree on path | one normalisation layer | path normalisation mismatch |
