### Details that matter

**Clock resolution and coarsening**  
- preconditions: `a page context able to read a high resolution timer`, `a host where isolation settings can be varied`
- oracle: `the observed granularity step, measured across many reads`, `the same step changing when isolation or site isolation settings change`, `a jitter distribution wider than the value being inferred, which ends the technique`

**JIT tier thresholds and deopt behaviour**  
- preconditions: `a script context that can time its own function calls`
- oracle: `a discontinuity in per call latency at a specific iteration count, repeatable`, `a deopt storm visible as a latency step when the argument type changes mid loop`

**WebAssembly compilation and memory growth**  
- preconditions: `the page can instantiate a WebAssembly module`
- oracle: `tier up timing of a wasm function against its JavaScript twin`, `an ArrayBuffer view detached after memory.grow, observed rather than documented`

**Allocator size classes and reuse order**  
- preconditions: `a script context with allocation primitives`, `a build with the target allocator`
- oracle: `objects of chosen sizes landing in adjacent regions, inferred from access timing`, `LIFO or FIFO reuse shown by address ordering after a controlled free sequence`, `a quarantine delay detected as a gap between free and reuse`

**Collector movement, finalizers and pause shape**  
- preconditions: `allocation pressure can be induced from script`
- oracle: `address stability across a forced collection`, `finalizer output ordered against a sentinel`, `pause distribution measured against a fixed workload`

**Sandbox reach and descriptor inheritance**  
- preconditions: `a renderer process to inspect on a host where it can be observed`
- oracle: `the seccomp policy and the open descriptor table, enumerated`, `a syscall refused at the policy and a neighbouring one permitted`, `a descriptor inherited into a helper that should not hold it`

**Native parser reachability from a page**  
- preconditions: `a page can load the media or document type in question`
- oracle: `the library that parses a crafted file, identified from a crash or a sandbox log`, `the accepted format list for a given engine version`

**GPU command and memory surface**  
- preconditions: `WebGL or WebGPU available in the target context`
- oracle: `the command set accepted and the validation applied to each`, `content of a fresh buffer before any write, which should be zero`

  - oracle: `a step or a discontinuity that repeats across runs`
- `Needs a host view`
  - **Is the target a renderer, a kernel boundary, or a native parser?**
  - `Renderer or sandbox`
    - action: enumerate the policy and the descriptor table, then probe reach
    - tools: `d37-sandbox-reach`

## Defense mirror

The other half of every row. An offensive entry with no matching detection and control is
incomplete, because the practical question is always against which defence.

| attack | detect | control | rule |
|---|---|---|---|
| cache timing against a quantised clock | timer granularity floor and jitter distribution monitored in the engine build | clock coarsening and jitter in the engine, per site isolation | a page deriving a value from a timing difference smaller than the quantisation step |
| renderer leak crossing an origin boundary | process boundary violations and renderer crash telemetry | site isolation, one renderer per site | a renderer reading memory belonging to another site's process |
| heap grooming after a free | allocator quarantine occupancy and reuse latency anomalies | quarantine before reuse, randomised freelist | an allocation landing at a freed address inside the quarantine window |
| reach past the sandbox after a renderer bug | seccomp denials and broker message validation failures | sandbox policy narrowing and broker argument validation | a syscall or broker call the policy should refuse |
| reading a GPU buffer left by another context | buffer initialisation audit on context creation | GPU memory clearing between contexts | non zero content in a buffer read before any write |
