## Decision tree

Machine readable at `trees/D17.json`. This is the rendered view.

- **Are you outside the estate or holding a credential?**
  - _why:_ The two positions have almost nothing in common. Outside means exposure. Inside means permission paths.
- `Outside`
  - action: look for the services that do not require a credential and are meant to be internal: buckets, metadata proxies, admin panels, storage listing
  - tools: `d17-cloudfox-ref`, `d17-hacktricks-cloud`
  - oracle: `data returned without authentication`
- `Holding a credential`
  - action: enumerate what it can do before using it. auth can-i list, or the provider equivalent, then map to paths
  - tools: `d17-kubectl`, `d17-cloudfox`, `d17-pathrunner`
  - oracle: `an action the credential should not permit`
- `A server side fetch primitive`
  - action: probe the metadata service with a token request first. IMDSv2 means no header equals no finding
  - tools: `d17-imds`
  - oracle: `credentials returned, or a token then credentials`
- `Posture review, no exploitation`
  - action: run a posture scanner with read only credentials, then rank by blast radius not by count
  - tools: `d17-prowler`, `d17-scoutsuite`, `d17-trivy`
  - oracle: `finding list with resource identifiers`

## Defense mirror

The other half of every row. An offensive entry with no matching detection and control is
incomplete, because the practical question is always against which defence.

| attack | detect | control | rule |
|---|---|---|---|
| metadata credential theft | request to the metadata address from an application process | IMDSv2, hop limit 1, egress deny | 169.254.169.254 access |
| IAM privilege escalation | action permitted by a policy that should not | least privilege, permission boundaries, SCPs | privilege escalation path monitor |
| exposed storage bucket | anonymous list or get success | block public access at the account level | anonymous access to object storage |
| over permissive role trust | role assumable by a broad principal | explicit principal, conditions, external id | role trust policy change |
| container escape prerequisites | privileged pod, host mount, or broad service account | pod security standards, no host namespaces | privileged workload admitted |
