# Attack ontology: moved

The generative model (16 atoms, carrier, sink, preconditions, oracle, mutation) now lives in the
patterns repo, `web-attack-atlas`, at `docs/ONTOLOGY.md` and machine readable at `data/atoms.json`.

Why it moved: atoms and patterns are thinking, not tooling. That repo outlives this one.

This repo keeps: tools, install, drivers, MCP wiring, REA, the corpus and the reconciliation ledger.
Cross reference at wave granularity; per pattern links are not in use. A pattern there names tools here,
and never the reverse.
